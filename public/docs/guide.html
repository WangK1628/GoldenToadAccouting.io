金蝉记账 · 使用指南

1. 登录与游客模式

  • 首次打开可选择登录 / 注册或稍后再说进入游客模式。
  • 验证码由服务器生成并发送到邮箱，页面不会显示验证码。
  • 注册成功后会在仓库 data/users/ 下新建该用户目录（GitHub 用户库）。
  • 注册用户可免费体验一次 AI，用过后需在设置中填写自己的 API Key。
  • 账单数据仍保存在设备本地 IndexedDB。

2. 手动记账

  • 首页底部输入框或「记一笔」打开记账面板。
  • 选择收支、分类、金额，保存后出现在流水列表。

3. AI 记账

  • 进入 设置 → AI 设置，填入 DeepSeek 或 OpenAI 兼容 API Key。
  • 打开 AI 记账，输入或语音说：「午饭花了 32」。
  • AI 通过 Tool Calling 自动记账，支持一次多笔。

4. 统计与预算

  • 统计：日/周/月/年趋势、分类占比、收支日历。
  • 预算：设置月度预算，首页圆环显示进度。

5. 数据管理

  • 支持 JSON / CSV / Excel / TXT 导入导出。
  • 清空数据需二次确认。

6. 安装

  • 网页版：Chrome / Edge 可「安装应用」到主屏幕（PWA）。
  • Android：从 Releases 下载 APK。
